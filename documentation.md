## Core Concepts

### 1. `RegisterRouter` - Auto CRUD

The main function that generates 5 RESTful endpoints from your struct.

#### Basic Usage

```go
package route

type Product struct {
    Id       string  `json:"id"`
    Name     string  `json:"name" binding:"required"`
    Price    float64 `json:"price" binding:"required,gt=0"`
    Category string  `json:"category"`
}

var ProductDB []Product

func init() {
    RegisterRouter(&ProductDB, "/api/products")
}
```

#### What Gets Created

| Method | Endpoint | Description | Request Body |
|--------|----------|-------------|--------------|
| `GET` | `/api/products` | List all items | - |
| `GET` | `/api/products/:id` | Get item by ID | - |
| `POST` | `/api/products` | Create new item | JSON object |
| `PUT` | `/api/products/:id` | Update item | JSON object |
| `DELETE` | `/api/products/:id` | Delete item | - |


### 2. `ResetableDatabase` - Initial State

Initialize your database with default data that can be reset anytime.

#### Syntax

```go
var DB []YourType = ResetableDatabase(&DB, []YourType{
    // initial data here
})
```

#### Example

```go
var ProductDB []Product

func init() {
    ProductDB = ResetableDatabase(&ProductDB, []Product{
        {Id: "1", Name: "Laptop", Price: 999.99, Category: "Electronics"},
        {Id: "2", Name: "Mouse", Price: 29.99, Category: "Accessories"},
        {Id: "3", Name: "Keyboard", Price: 79.99, Category: "Accessories"},
    })
    
    RegisterRouter(&ProductDB, "/api/products")
}
```

#### Reset Endpoint

EZAPI-GO automatically creates a reset endpoint:

```bash
# Reset ALL modules to initial state
curl -X POST http://localhost:8080/api/reset
```

**Response:**
```json
{
    "success": true,
    "message": "All modules reset to initial state"
}
```

**⚠️ Warning:** This deletes ALL current data across all modules.

### 3. `RegisterRouterWith` - Custom Endpoints

Add custom logic alongside auto-generated CRUD endpoints.

#### Syntax

```go
RegisterRouterWith(func(router *gin.Engine) {
    // Your custom routes here
})
```

#### Example: Search Endpoint

```go
func init() {
    // Standard CRUD
    RegisterRouter(&ProductDB, "/api/products")
    
    // Custom search
    RegisterRouterWith(func(router *gin.Engine) {
        router.GET("/api/products/search", func(c *gin.Context) {
            query := c.Query("q")
            var results []Product
            
            for _, product := range ProductDB {
                if strings.Contains(
                    strings.ToLower(product.Name),
                    strings.ToLower(query),
                ) {
                    results = append(results, product)
                }
            }
            
            SendSuccess(c, results)
        })
    })
}
```

**Usage:**
```bash
curl "http://localhost:8080/api/products/search?q=laptop"
```

#### Example: Category Filter

```go
RegisterRouterWith(func(router *gin.Engine) {
    router.GET("/api/products/category/:category", func(c *gin.Context) {
        category := c.Param("category")
        var filtered []Product
        
        for _, p := range ProductDB {
            if strings.EqualFold(p.Category, category) {
                filtered = append(filtered, p)
            }
        }
        
        SendSuccess(c, filtered)
    })
})
```

**Usage:**
```bash
curl http://localhost:8080/api/products/category/Electronics
```

#### Example: Statistics Endpoint

```go
RegisterRouterWith(func(router *gin.Engine) {
    router.GET("/api/products/stats", func(c *gin.Context) {
        var total float64
        var count int
        categories := make(map[string]int)
        
        for _, p := range ProductDB {
            total += p.Price
            count++
            categories[p.Category]++
        }
        
        stats := map[string]interface{}{
            "total_products": count,
            "total_value": total,
            "average_price": total / float64(count),
            "categories": categories,
        }
        
        SendSuccess(c, stats)
    })
})
```

### 4. Dependency Injection - Cross-Module Data

Access data from other modules using getter functions.

#### Problem

```go
// ❌ Won't work - circular import
package route

type Order struct {
    ProductId string
    Product   Product // Can't access directly!
}
```

#### Solution: Getter Functions

```go
// route/product.go
package route

var ProductDB []Product

func GetProductById(id string) *Product {
    for i := range ProductDB {
        if ProductDB[i].Id == id {
            return &ProductDB[i]
        }
    }
    return nil
}
```

```go
// route/order.go
package route

type Order struct {
    Id        string `json:"id"`
    ProductId string `json:"product_id"`
}

var OrderDB []Order

func init() {
    RegisterRouterWith(func(router *gin.Engine) {
        router.GET("/api/orders/:id/full", func(c *gin.Context) {
            id := c.Param("id")
            
            // Find order
            var order *Order
            for i := range OrderDB {
                if OrderDB[i].Id == id {
                    order = &OrderDB[i]
                    break
                }
            }
            
            if order == nil {
                SendError(c, "Order not found", http.StatusNotFound)
                return
            }
            
            // Get related product
            product := GetProductById(order.ProductId)
            
            // Return combined data
            result := map[string]interface{}{
                "order": order,
                "product": product,
            }
            
            SendSuccess(c, result)
        })
    })
}
```

## API Reference

### Helper Functions

#### `SendSuccess(c *gin.Context, data interface{})`

Send successful response with data.

```go
SendSuccess(c, map[string]interface{}{
    "message": "Operation successful",
    "count": 5,
})
```

**Response:**
```json
{
    "success": true,
    "data": {
        "message": "Operation successful",
        "count": 5
    }
}
```

#### `SendError(c *gin.Context, message string, statusCode int)`

Send error response.

```go
if product == nil {
    SendError(c, "Product not found", http.StatusNotFound)
    return
}
```

**Response:**
```json
{
    "success": false,
    "message": "Product not found"
}
```

#### `SendValidationError(c *gin.Context, err error)`

Send validation error with details.

```go
if err := c.ShouldBindJSON(&product); err != nil {
    SendValidationError(c, err)
    return
}
```

**Response:**
```json
{
    "success": false,
    "message": "Validation failed",
    "details": [
        "Name is required",
        "Price must be greater than 0"
    ]
}
```

## Response Format

All API responses follow a consistent structure.

### Success Response

```json
{
    "success": true,
    "data": { ... }
}
```

**Examples:**

```json
// Single item
{
    "success": true,
    "data": {
        "id": "1",
        "name": "Laptop",
        "price": 999.99
    }
}

// List of items
{
    "success": true,
    "data": [
        {"id": "1", "name": "Laptop", "price": 999.99},
        {"id": "2", "name": "Mouse", "price": 29.99}
    ]
}

// Empty list
{
    "success": true,
    "data": []
}

// Custom data
{
    "success": true,
    "data": {
        "total": 10,
        "message": "Operation completed"
    }
}
```

### Error Response

```json
{
    "success": false,
    "message": "Error description"
}
```

**Common Errors:**

```json
// Not found (404)
{
    "success": false,
    "message": "Product not found"
}

// Bad request (400)
{
    "success": false,
    "message": "Invalid product ID"
}

// Internal error (500)
{
    "success": false,
    "message": "Internal server error"
}
```

### Validation Error Response

```json
{
    "success": false,
    "message": "Validation failed",
    "details": [
        "Field 'Name' is required",
        "Field 'Price' must be greater than 0",
        "Field 'Email' must be a valid email address"
    ]
}
```
